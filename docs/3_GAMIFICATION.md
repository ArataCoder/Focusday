# 3. Конкурентный анализ и ADHD-геймификация

## Сравнение
| | Habitica | Notion | Things 3 | Routine | Finch | **Focusday** |
|---|---|---|---|---|---|---|
| Платформа | все | все | только Apple | Mac/Win/iOS | мобильные | **Windows, офлайн** |
| Геймификация | полная RPG | нет | нет | нет | питомец растёт за заботу о себе | XP + мягкие достижения |
| Наказание за пропуск | **да: теряешь HP, «умираешь»** | — | — | — | нет | **нет, пропуск = пауза** |
| Порог входа | средний | **высокий** (нужно строить систему) | низкий | средний | низкий | низкий |
| Микро-шаги | чек-листы | вручную | чек-листы | — | мини-цели | шаги + «Помоги начать» + следующий шаг в фокусе |
| Фокус-таймер / виджет поверх окон | — | — | — | календарь | — | **да** |
| Ощущение «премиум» | пиксель-арт | минимализм | эталон | премиум | мило | Heavy iOS / стекло |

**Чему учимся:** у Things 3 — спокойствию и скорости ввода; у Finch — награде за «просто пришёл»; у Habitica — силе RPG-метафоры, **но без наказаний** (у людей с СДВГ потеря «жизни» или стрика запускает стыд и уход из приложения).
**Наша ниша:** десктопный «тихий напарник» — плавающий виджет, быстрый захват из любой программы, мягкая геймификация.

## Принципы (зашиты в код)
1. **Нет потерь.** XP и уровни только растут. Нет «стрика подряд» — вместо него «Ритм, а не цепь»: 4 активных дня из любых 7.
2. **Возвращение — главный подвиг.** Пауза 3+ дня → эпическое достижение, +30 XP и ×2 XP за первую задачу.
3. **Начало = победа.** XP за каждый микро-шаг; достижение за 1 шаг из 3.
4. **Честность к энергии.** Награда за задачу в день низкой энергии и за закрытие просроченной («Без чувства вины»).
5. **Анти-фарм.** XP за задачу и шаг выдаётся один раз (`task.xp`, `step.x`); повторное «выполнено» после отмены ничего не даёт; за быстрый захват — максимум 10 XP в день.
6. **Любопытство.** Скрытые достижения и редкость (обычное → легендарное), как в Steam.

## 26 достижений (реализованы)
**Возвращение:** Возвращение легенды (эпич.) · Феникс — 5 возвращений (легенд.) · Снова здесь · Ритм, а не цепь (редк.)
**Микро-шаги:** Микро-победа · Дробитель (3+ шага) · Мастер маленьких шагов — 25 шагов (редк.) · Архитектор (редк.)
**Задачи без давления:** Первая победа · Десять шагов · Сотня (эпич.) · Без чувства вины (редк.) · Честный заряд (редк.) · Комбо ×3 (редк.) · Ритм дня (редк.)
**Время:** Ночной дозор (после 22:00) · Ранняя пташка · Мягкие выходные
**Фокус:** В потоке · Железный фокус (эпич.) · Перезапуск
**Организация:** Разгрузка головы · Ритм без пауз · Архивариус (редк.) · Подушка безопасности (первый бэкап)
**Секретное:** «Свой темп» — 10 уровень (легенд.)

## UI-компоненты
- **Карточка уровня** в сайдбаре: кольцо прогресса, титул, полоса XP; при получении опыта — пружинный «бамп».
- **«+15 XP»** вылетает из чекбокса/шага и тает.
- **Всплывающая карточка достижения** (сверху справа): стекло, цвет редкости, иконка «выпрыгивает» с поворотом, блик проходит по карточке, звук-арпеджио (Web Audio). Очередь — по одной, 4,6 с, клик открывает коллекцию.
- **Level Up:** затемнение с размытием, большая цифра с пружиной, вращающееся свечение, конфетти, отдельный аккорд.
- **Коллекция:** сводка (уровень, достижения, возвращения, микро-шаги, дни из 30), карточки по редкости, прогресс-бары для счётных, даты открытия, скрытые «???».
- Всё отключается при `prefers-reduced-motion`.

## Ключевой фрагмент
```js
function award(event, p = {}) {
  const s = S(); let xp = 0;
  if (event === 'task') {
    const t = p.task; if (t.xp) return;               // анти-фарм
    s.tasksDone++;
    if (data.energy <= 2) s.lowEnergyWins++;            // «Честный заряд»
    if (t.date < todayISO()) s.guiltFree++;             // «Без чувства вины»
    xp = 10 + (t.priority === 3 ? 5 : 0) + Math.min(10, Math.round(t.duration / 10));
    if (s.comebackDay === todayISO()) { xp *= 2; s.comebackDay = null; }   // бонус возвращения
    t.xp = xp;
  }
  if (xp) gainXP(xp, p.anchor);                         // «+XP» + проверка Level Up
}
```
