# 6. Focusday 1.3 — что сделано и зачем

## Оценка: насколько это полезно для человека с СДВГ
| Функция | Польза | Почему |
|---|---|---|
| **Котик-напарник (body doubling)** | ★★★★★ | «Тело рядом» — один из самых рабочих приёмов при СДВГ: присутствие другого (даже виртуального) снижает уход в телефон. Котик не давит: сидит, моргает, машет хвостом; будит **только** при реальном простое. |
| **Детектор простоя 15–20 мин** | ★★★★★ | Ловит главный провал — «залип в ленте, таймер тикает». Вопрос без упрёка: «Ты всё ещё в потоке или сделаем паузу? 🐾». Пауза — легальный выбор, за честный перерыв даже дают XP. |
| **Мягкий перенос** | ★★★★☆ | Убирает «красные просрочки» — главный источник стыда и избегания приложения. Перенос = план, а не провал; есть «Отменить». |
| **Ctrl+K палитра** | ★★★★☆ | Меньше кликов = меньше шансов отвлечься между «хочу сделать» и «сделал». Поиск по задачам, привычкам, мыслям, командам; `Добавить: …` создаёт что угодно через синтаксис Q. |
| **Фоновые звуки** | ★★★★☆ | Коричневый/розовый шум и «кафе» многим с СДВГ помогают держать внимание. Включаются вместе с фокусом и плавно гаснут в конце — мягкий сигнал без резкого звонка. |
| **Цитаты без грусти** | ★★★☆☆ | Мелочь, но ежедневный тон важен. Мрачные цитаты по умолчанию скрыты, любую можно убрать навсегда. |
| **Синхронизация ПК ⇄ телефон** | ★★★★☆ | Мысль, пришедшая в магазине, не теряется. Сквозное шифрование — сервер не видит ничего. |

Чего сознательно **нет**: штрафов за паузы, красных счётчиков просрочки, звонков каждые 5 минут (в 1.1–1.2 был навязчивый виджет — убран), «стрик сгорел».

## Котик-компаньон и детектор простоя
* **Когда виден:** только во время фокус-сессии (выключается в «Настройки → Котик-напарник»).
* **Живость:** случайное моргание каждые 3–7 с, хвост, дыхание, глаза «следят». `prefers-reduced-motion` — анимации выключаются.
* **Когда будит:** одновременно (1) идёт фокус, (2) нет мыши/клавиатуры ≥ N минут (10/15/20/30, по умолчанию 15), (3) с прошлого вопроса прошло ≥ N минут.
* **Источники простоя:**
  * EXE (Windows) — `GetLastInputInfo`: ввод в **любой** программе (Word, браузер, IDE). Читаешь статью и крутишь колесо — котик молчит.
  * Браузер Chrome/Edge — Idle Detection API (по разрешению: кнопка в настройках).
  * Другое — котик просто сидит рядом, не будит.
* **Кнопки:** «Продолжаю 🐾» (ещё N минут тишины) · «Взял паузу ☕» (пауза таймера + перерыв 5 мин с обратным отсчётом, «+5 минут», «Вернуться раньше») · «Не беспокоить в эту сессию».
* Не ответил 10 минут → таймер сам ставится на паузу (честная статистика фокуса), котик ждёт.
* **В EXE** котик живёт в отдельном прозрачном окне **поверх всех программ** (правый нижний угол, без рамки, не в панели задач, не отбирает фокус): 132×132, а с вопросом — 340×250. Кнопка Focusday в панели задач мягко мигает.
* Достижение «Честный перерыв» и +3 XP за паузу по подсказке (до 3 раз в день).

## Цитаты
* 37 цитат, категории: Поддержка · Дисциплина и дело · Бэтмен и DC · Аниме · Самураи · Классика. Включай/выключай чипами в настройках.
* **Атрибуции проверены.** Пример: «У тебя нет врагов…» — **Торс** (отец Торфинна), *Vinland Saga*; Миямото Мусаси — «Книга пяти колец»; Хагакурэ — Ямамото Цунэтомо. Если формулировка — пересказ, стоит пометка «по мотивам», если авторство спорное — «приписывается».
* **Тон:** `gentle` (поддержка), `drive` (толчок), `deep` (грустные/мрачные — Ичиго, «умереть героем» Харви Дента, Гатс). `deep` по умолчанию **скрыты** — переключатель «Показывать грустные и мрачные».
* **Ротация:** раз в 5 минут; при возвращении в окно — только если тебя не было > 2,5 минуты. Без повторов подряд (последние 8 не повторяются). Плавная смена.
* **«Больше не показывать эту»** (иконка глаза на карточке) — с отменой; «Вернуть скрытые» в настройках.
* Свои цитаты: «Загрузить JSON» — `[{"text":"…","author":"…","source":"…","tone":"gentle"}]` или массив строк.

## Библиотека звуков
Все звуки синтезируются Web Audio в реальном времени (без mp3, без интернета, бесконечные, без «шва» петли):
Дождь · Кафе · Библиотека · Коричневый шум · Розовый шум · Океан · Камин · Ветер. Громкость выровнена офлайн-рендером (≈ −26 dBFS), тест проверяет, что каждый звучит и не клиппует.
Режим «Включать вместе с фокусом»: старт с таймером, пауза — затухание 1,5 с, последние 10 секунд сессии — плавный fade-out.

## Мягкий перенос («Бережный план»)
* Днём: «С прошлых дней осталось 3 задачи — перенести на сегодня».
* С 18:00: «Вечер — время закрывать день» → всё незавершённое за сегодня и раньше переезжает на завтра.
* Рутины (повторяющиеся) не трогаются. Всегда есть «Отменить». +5 XP раз в день, достижение «Бережный план».

## Command Palette — Ctrl+K
Нечёткий поиск (буквы по порядку: «нф» → «Начать фокус»), ↑/↓, Enter — выполнить, Shift+Enter — фокус на задаче. Группы: действия, переходы, звуки, данные, задачи, привычки, мысли. `/` — поиск по задачам.
