# Focusday 1.2 — Привычки, микро-финансы и мысли без перегруза

Для кого: СДВГ, выгорание, «я опять забросил трекер на 4-й день».
Главная метрика: **человек возвращается после пропуска**, а не «длина цепочки».

## 1. Что делают конкуренты — и где ломаются

| Продукт | Что хорошо | Ошибка для СДВГ/выгорания | Что берём / чего избегаем |
|---|---|---|---|
| **Habitica** | RPG, награды, социальность | Наказание: пропуск = минус HP, смерть персонажа, урон всей группе. Три типа сущностей (Habits/Dailies/To-Do), десятки настроек, пиксельный визуальный шум | Берём: XP за действие. Избегаем: любых штрафов и «смерти» |
| **Streaks** | 1 тап, красивые кольца, виджеты iOS | Пропуск обнуляет цепочку → «всё пропало, брошу». Лимит 24 задачи, только Apple | Берём: кольцо и 1 тап. Избегаем: обнуления |
| **Finch** | Самый бережный тон, питомец, рефлексия | Медленно: много экранов до отметки, мобильный, тяжёлая инфантильная эстетика, часть функций за подпиской | Берём: тон «без вины», настроение. Избегаем: длинного онбординга |
| **Routinery** | Пошаговые рутины с таймером | Жёсткие последовательности: сбился на шаге 2 — рутина «сломана». Paywall | Берём: минимальную версию. Избегаем: обязательного порядка |
| **Notion-шаблоны** | Гибкость, всё в одном | Настройка часами, нет обратной связи и анимаций, формулы, таблицы = шум; трекер превращается в проект | Берём: «всё в одном месте». Избегаем: ручной настройки |

Общие паттерны провала: **наказание**, **сложная структура до первой пользы**, **визуальный шум**, **чувство долга** (красные цифры, «пропущено 5 дней»).

## 2. Принципы Zero-Friction & No-Guilt

1. **Одно поле — всё.** Любая запись — через `Q` из любого места, ≤ 3 секунды, без выбора раздела.
2. **Отметка = 1 тап.** Виджет в правой колонке, без перехода на страницу.
3. **Ничего не сгорает.** Нет HP, нет обнуления, нет красного. Перерасход — янтарный («бывает»).
4. **Минимальная версия засчитывается полностью.** «5 минут у подъезда» = прогулка.
5. **Пауза вместо провала.** Отпуск/болезнь → «Пауза», статистика заморожена.
6. **Тишина по умолчанию.** Один акцент на карточку, вторичное — свернуть.
7. **Награда за возвращение,** а не за безупречность (достижение «Бережно к себе», «Ритм недели»).

## 3. Гибкий стрик (не ломается от одного пропуска)

- Цель привычки — **N раз в неделю** (1–7), а не «каждый день».
- **Ритм** = отметки текущей недели / N (кольцо).
- **Стрик** = подряд недель, где цель достигнута. **Текущая неделя никогда не обрывает стрик** — она ещё идёт.
- **Всего** = все отметки за всё время — **никогда не уменьшается**.
- `Минимум` (½-кружок) и `Сделано` (полный) считаются одинаково.
- Пауза: интервалы пауз хранятся в `pauses`; неделя, задетая паузой, нейтральна — стрик не рвётся и не растёт.
- Прошлые дни недели можно отметить задним числом (клик по точке: нет → сделано → минимум → нет).

## 4. Low-Energy Mode (клавиша `L` или кнопка-батарейка)

| Что меняется | Как |
|---|---|
| Задачи «Сегодня»/«Входящие» | Только 3 самые короткие невыполненные + баннер «Показать все» |
| Интерфейс | Скрыты календарь, метрики, активность, подсказки; акцент становится мягким шалфейным |
| Привычки | Клик в виджете ставит **минимум**, а не полную версию |
| Тексты | «Бережный режим. Сегодня достаточно трёх маленьких дел» |
| Подсказка | Если энергия ≤ 1 — приложение само предлагает режим |

## 5. Размещение виджетов (Heavy iOS / Luxury)

```
┌ Sidebar ─────┐┌ Main ───────────────────────────┐┌ Right rail ──────────┐
│ Пространства ││ Заголовок дня                    ││ Фокус-зона (таймер)  │
│ ДЛЯ СЕБЯ     ││ [Q  Задача · @привычка · -$5 …]  ││ ┌ Для себя ────── ⌄ ┐│
│  Привычки 2/3││ Календарь · Метрики · Список      ││ │ ◉ ◉ ○  (кольца)   ││
│  Финансы 12€ ││                                  ││ │ 💳 12 € осталось   ││
│  Мысли 2     ││                                  ││ │ ✎ 2 мысли сегодня  ││
└──────────────┘└──────────────────────────────────┘│ └───────────────────┘│
```
- Иерархия: **задача дня > фокус > «Для себя»**. Модули не конкурируют с главным списком.
- Виджет: стеклянная карточка, кольца 42 px (как Apple Activity), одна цифра денег, одна строка мыслей. Сворачивается (запоминается).
- Страницы модулей открываются в той же колонке (без модалок), на 5/6/7.
- В режимах Focus и Compress виджет скрыт.

## 6. Универсальный ввод `Q`

| Ввод | Результат |
|---|---|
| `Позвонить в банк завтра 15м !!` | Задача (дата, длительность, важность — как раньше) |
| `@вода` | Отметить привычку «Вода» (нет такой — создаётся) |
| `@прогулка мин` | Отметить **минимальную** версию |
| `-$4,5 кофе #еда` | Расход 4,50, заметка «кофе», тег «еда» (запятая или точка) |
| `+$500 зарплата` | Доход |
| `?$80 наушники` | Хотелка → Cool-off Chamber |
| `!мысль любого размера` | Запись в дневник |

Под полем — живой чип-подсказка, что именно будет создано, **до** нажатия Enter.

## 7. Cool-off Chamber (антиимпульсивные покупки)

1. Хотелка (`?$`) уходит в карантин на 24 ч (настраивается 12/24/48/72); дорогие (≥ 3× порога) — 72 ч.
2. Если обычный расход больше порога импульса (30 € по умолчанию) — тост предлагает «В карантин».
3. Когда время вышло — кольцо становится мятным: «всё ещё хочется?»
4. **Отпустить** → сумма идёт в «сэкономлено», +10 XP, достижение «Холодная голова».
5. **Купить** → расход с тегом «обдуманно», без упрёков. Купить раньше тоже можно.

Дневной лимит: одна большая цифра «осталось сегодня», график 7 дней с линией лимита. Перерасход — янтарный, не красный.

## 8. Данные, схема v4, экспорт/импорт

```js
habits:   [{ id, name, minText, target, color, paused, pausedAt, pauses:[[from,to]], log:{ 'YYYY-MM-DD': 1|2 }, updatedAt }]
money:    { currency, dailyLimit, impulse, coolHours, saved, updatedAt }
expenses: [{ id, type:'in'|'out', amount, note, tag, date, at, updatedAt }]
chamber:  [{ id, title, price, addedAt, until, status:'waiting'|'bought'|'released' }]
thoughts: [{ id, text, mood:0–5, at, updatedAt }]
```
- **Экспорт** — один `.json` (или зашифрованный `.fdbak`): задачи, списки, привычки, финансы, мысли, достижения, XP, настройки; `schema: 4`, `counts`, `checksum` SHA-256.
- **Импорт** — предпросмотр (сколько новых/обновится, в т. ч. «Привычки · финансы · мысли»), затем «Слить» или «Заменить».
- Слияние: по `id`, новее `updatedAt` побеждает; надгробия удалений уважаются; логи привычек **объединяются** (отметка с любого ПК сохраняется); `saved` = максимум.
- Старые бэкапы v1–v3 открываются: недостающие разделы создаются пустыми (`ensureLife`).
