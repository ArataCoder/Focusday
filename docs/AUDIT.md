# Focusday — технический аудит и что исправлено

Уровни: 🔴 критично · 🟠 важно · 🟡 косметика/долг

## 1. Архитектура и десктоп
| # | Проблема | Ур. | Решение |
|---|---|---|---|
| 1 | Проект на **Electron** (≈150 МБ EXE), а цель — Tauri | 🟠 | Новый `src-tauri/` (Tauri v2, EXE ~8–12 МБ), фронт не переписан |
| 2 | Кнопка «Пауза» в оверлее делает `executeJavaScript("…focusStartBtn.click()")` — хрупко, ломается при переименовании id, это дыра в изоляции | 🔴 | Событие `focusday://overlay-action` → `onOverlayAction()` в приложении |
| 3 | `publishState` на **каждый** `persist()` (IPC-спам, 4 раза/сек во время таймера) | 🟠 | Отправка только при изменении состояния (diff по JSON) |
| 4 | «Продолжаю» и «Скрыть» в оверлее делали одно и то же | 🟡 | «Продолжаю» = отложить напоминание на 5 мин; добавлена кнопка «✓ Готово» |
| 5 | Закрытие окна убивает таймер фокуса | 🟠 | Крестик сворачивает в трей, выход — через меню трея |
| 6 | Второй запуск EXE открывал вторую копию → гонка за localStorage | 🟠 | `tauri-plugin-single-instance` |

## 2. JavaScript
| # | Проблема | Ур. | Решение |
|---|---|---|---|
| 7 | `persist()` (синхронная запись localStorage + JSON.stringify всего состояния) вызывается десятки раз за действие и каждые 5 с | 🟠 | Debounce 120 мс + принудительный flush на `beforeunload`/`visibilitychange` |
| 8 | `timerTick` каждые 250 мс перерисовывает фокус-карточку и раз в 5 с — весь список задач | 🟠 | DOM трогается только при смене секунды; список — только если есть задача «в процессе» |
| 9 | `renderFocus()` вызывает `persist()` — побочный эффект в рендере | 🟠 | Убрано |
| 10 | `renderHeader` пересоздаёт `#taskCountBadge` через `innerHTML` (дубль логики с `renderTasks`, id теряет слушатели) | 🟠 | Заголовок через `textContent`, бейдж — отдельный элемент |
| 11 | Календарь: стрелки двигали `calendarOffset` на 1, а дату на 14 дней; после рестарта сетка и выбранный день расходились | 🔴 | Диапазон вычисляется из `selectedDate` — всегда согласован |
| 12 | Достижение «Создай 5 списков» проверяло `lists.length >= 9` (ломается, если удалить стандартный список) | 🟡 | Считаются только пользовательские списки |
| 13 | `catch` в `persist()` обращался к `#storageStatus` без проверки на null | 🟡 | Null-safe |
| 14 | `syncSoundButtons` затирал иконку `textContent = '♫'` | 🟡 | Меняется только `aria-pressed`/`title` |
| 15 | Удаление через блокирующий `confirm()` — для СДВГ это лишнее трение | 🟠 | Удаление сразу + тост «Отменить» 6,5 с |
| 16 | Цвет кольца прогресса/таймера захардкожен в JS (`#ffffff0b`, `var(--purple)`) — светлая тема ломалась | 🟠 | JS ставит только `--p`, цвета — в CSS |
| 17 | Инлайн-стиль `style="color:var(--mint)"` в шаблоне задачи | 🟡 | Класс `.live-chip` |
| 18 | Поиск перерисовывал список на каждое нажатие | 🟡 | Debounce 120 мс |
| 19 | `viewMode` (компактный вид) не сохранялся | 🟡 | Сохраняется + `aria-pressed` |
| 20 | Хоткеи `1`/`2` нарисованы в меню, но не работали; `N` не работал в русской раскладке | 🟠 | `1–4`, `F`, `C`, `Q`, `Space` + русская раскладка (т/а/с/й) |
| 21 | Пустые обработчики: `calendarGrid.addEventListener('click',()=>{})`, `steps.forEach(s=>{})` | 🟡 | Удалены |
| 22 | Модалки: нет возврата фокуса, Esc закрывал «ничего» | 🟡 | Возврат фокуса, автофокус первого поля, `body.modal-open` |
| 23 | Стек тостов без лимита | 🟡 | Максимум 4, анимация ухода |

## 3. CSS (46 КБ → один проход)
| # | Проблема | Ур. |
|---|---|---|
| 24 | 4–5 «полировочных проходов» перекрывают друг друга: светлая тема объявлена 4+ раза, `prefers-reduced-motion` — 4 раза, `.task-card` animation — 3 раза, `--muted` переопределён | 🔴 |
| 25 | Селектор `.calendar-day` не существует (в JS `.day-cell`), `.timer-value`/`.timer-display` — мёртвые | 🟠 |
| 26 | Шрифты `DM Sans`/`Manrope` указаны, но **нигде не подключены** → случайный fallback | 🟠 |
| 27 | Размеры 8–10 px, потом «заплатки» `font-size:max(11px,.78em)` | 🟠 |
| 28 | Захардкоженные `#191a23`, `#1c1b28`, `#1a1b25` в псевдоэлементах → светлая тема с тёмными дырами | 🟠 |
| 29 | `html,body{overflow-x:clip}` маскировал реальные переполнения | 🟠 |
| 30 | `backface-visibility`/`translateZ(0)` на всех карточках → лишние GPU-слои | 🟡 |
| 31 | Анимация удаления по `max-height`/`padding` (layout thrash) | 🟡 |
| 32 | `button:active{transform}` конфликтует с `:hover{translate}` | 🟡 |
| 33 | Hover-подъём на неинтерактивных карточках обзора | 🟡 |
| 34 | Колонки графика `min 42px` → горизонтальный скролл на телефоне | 🟡 |

**Новый CSS:** токены → база → layout → компоненты → ADHD-режимы → motion → responsive. Каждый селектор объявлен один раз, все цвета через переменные, шрифт ≥ 12 px, анимации только `transform/opacity`, blur только на крупных панелях. Проверено: 1440 / 1280 / 390 px, тёмная и светлая темы, 0 ошибок JS, 0 горизонтальных переполнений.

## 4. HTML
- Эмодзи/юникод-иконки (✳ ◷ ↳ ▦ ♫) на Windows рендерятся разными шрифтами → заменены на SVG-спрайт.
- Всем кнопкам добавлен `type="button"` (кнопки в формах раньше могли отправлять форму).
- Поиск без доступного имени → `sr-only` label; `kbd` «⌘ K» на Windows → «Ctrl K».
- `href="#today"` у логотипа → кнопка.
- Модалки разбиты на `modal-head / modal-body (скролл) / modal-actions` — футер больше не «едет».
- Все id сохранены — данные пользователя и экспорт/импорт совместимы.
