## Следующий спринт (1–2 недели)
| Фича | Зачем | Как |
|---|---|---|
| **Звуковой «пак» премиум-уровня** | тактильность | Звук = 2 осциллятора + шум с огибающей; громкость −24 dB; «тики» таймера по выбору; учитывать тихий режим Windows (Focus Assist) через Rust |
| **Интерактивный виджет фокуса 2.0** | меньше переключений | кольцо прогресса в оверлее, перетаскивание с «прилипанием» к углам, сворачивание в «пилюлю» 120×36, правый клик → «+5 минут» |
| **Haptic-подобная анимация** | дофамин | `@property` + spring для чисел (count-up XP), «желейный» чекбокс через `linear()` easing |
| **Mica / Acrylic в Windows 11** | нативный «люкс» | `window-vibrancy` crate → `apply_mica(&window)`; фон body прозрачный |
| **Темы-награды** | мотивация без давления | акценты «Аврора», «Сакура», «Титан» открываются на уровнях 3/5/8 |

## Дальше (месяц)
- **Команды Ctrl+K (command palette)** как в Raycast/Linear: поиск + действия («перенести всё просроченное на сегодня»).
- **Тайм-блокинг:** перетаскивание задачи на календарь дня (стиль Cron).
- **Body doubling:** фоновые звуки «кафе / дождь / библиотека» в фокус-сессии.
- **«Мягкий перенос»:** вечером одна кнопка «перенести несделанное на завтра» + достижение «Бережный план».
- **Статистика-рефлексия:** «лучшее время дня для фокуса» по тепловой карте часов.
- **Хранилище в файле** (`tauri-plugin-store` / SQLite) вместо localStorage + авто-обновления (`tauri-plugin-updater`).
- **Мобильный компаньон** (Tauri Mobile или PWA) с той же синхронизацией.
