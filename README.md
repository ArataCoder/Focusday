# Focusday 1.3 — котик-напарник, синхронизация с телефоном, закреплённый код

**Попробовать сразу:** открой `src/focusday.html` в Edge/Chrome.
**Собрать EXE без Rust:** загрузи папку в GitHub → Actions → «Release Windows» (сначала пройдут автотесты) — см. `docs/1_RELEASE_GUIDE.md`.
**Собрать локально:** `npm install` → `npm test` → `npm run build` (нужны Rust + WebView2).
**На телефон:** PWA за 5 минут или APK через Tauri 2 — `docs/8_MOBILE_BUILD.md`.

## Новое в 1.3
* 🐾 **Котик-напарник** сидит в углу во время фокуса (моргает, машет хвостом). Нет мыши/клавиатуры 15 минут (в EXE — во всей Windows) → «Ты всё ещё в потоке или сделаем паузу? 🐾» · «Продолжаю 🐾» / «Взял паузу ☕» (перерыв 5 мин). В EXE — отдельное окно поверх всех программ. Навязчивый виджет «каждые 5 минут» убран.
* 🔒 **Синхронизация ПК ⇄ телефон** со сквозным шифрованием: облачная папка (Google Drive/OneDrive/iCloud/Dropbox) и/или бесплатный Supabase.
* 💬 **Цитаты**: 37 шт. с проверенными авторами, 6 категорий, грустные скрыты, смена раз в 5 минут и после отсутствия > 2,5 мин, «Больше не показывать эту», импорт JSON.
* 🌧 **Звуки**: дождь, кафе, библиотека, коричневый/розовый шум, океан, камин, ветер; громкость, старт с фокусом, плавное затухание в конце.
* 🌙 **Мягкий перенос** хвостов на сегодня/завтра одной кнопкой + достижение «Бережный план».
* ⌘ **Ctrl+K** — палитра команд с нечётким поиском.
* 🧱 Код разбит на ES-модули (`src/js/`), сборка esbuild, 10 юнит- и 7 E2E-тестов, CI гоняет тесты перед сборкой EXE. PWA-манифест и офлайн-режим.

Горячие клавиши: `Ctrl K` палитра · `/` поиск · `Q` захват · `N` задача · `Space` фокус · `F` режим фокуса · `C` сжатие · `L` бережный режим · `1–4` задачи · `5` привычки · `6` финансы · `7` мысли · глобально `Ctrl Alt Space` / `Ctrl Alt F`.

Разработка: `npm run bundle:watch` (правишь `src/js/*`, `src/focusday.js` пересобирается сам) · `npm test` · `npm run test:e2e`.
