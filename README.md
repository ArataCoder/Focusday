## Быстрый старт: от клона до тестов

Для веб-сборки и тестов достаточно **Git** и **Node.js 24 LTS с npm**.
Установите их с [git-scm.com](https://git-scm.com/downloads) и
[nodejs.org](https://nodejs.org/), затем откройте новый терминал.
Rust, Android SDK, Supabase и ключи API для этого пути не нужны.

```sh
git --version
node --version
npm --version
git clone https://github.com/ArataCoder/Focusday.git
cd Focusday
npm ci
npm run bundle
npm test
```

Ожидаемый результат: собран `src/focusday.js`, все 17 юнит-тестов проходят.
Исходники — `src/js/*`; не редактируйте сгенерированный `src/focusday.js`.
`package-lock.json` фиксирует npm-зависимости; после изменения зависимостей
используйте `npm install` и коммитьте обновлённый lockfile.

### E2E в Chromium

Из корня клона, после `npm ci`:

```sh
npx playwright install --with-deps chromium
npm run test:all
```

На Linux установка системных библиотек браузера требует root/sudo.
При отсутствии этих прав администратор должен установить библиотеки заранее;
затем достаточно `npx playwright install chromium`. После обновления Playwright
повторите установку браузера. `test:all` запускает юнит-тесты, сборку и три
E2E-набора (интерфейс, PWA и имитация окна котика), **не** настоящий EXE.
Если браузер уже установлен вручную, тесты поддерживают `CHROMIUM_PATH` с путём
к исполняемому файлу; обычно эта переменная не нужна.

### Открыть веб-приложение

```sh
npm run pwa:serve
```

Команда сначала собирает JavaScript, затем запускает локальный сервер.
Откройте **http://localhost:3000/focusday.html**, не `/` (в проекте нет `index.html`).
Остановка — `Ctrl+C`. После изменения `src/js/*` выполните `npm run bundle`
или запустите `npm run bundle:watch` в другом терминале и обновите страницу.
Для установки PWA на телефон нужен HTTPS-хостинг; см. [мобильное руководство](docs/8_MOBILE_BUILD.md).

### Windows EXE и мобильные сборки — отдельные пути

`npm run build` — **нативная Tauri-сборка**, а не веб-сборка. Для Windows нужны
Rust MSVC, C++ Build Tools и WebView2: [пошаговая инструкция](docs/TAURI_GUIDE.md).
Текущие установщики настроены только для Windows (NSIS/MSI); на Linux/macOS
используйте веб-путь выше, а не `npm run build` для Windows EXE.
[Релиз и артефакты](docs/1_RELEASE_GUIDE.md) ·
[Android/iOS и PWA](docs/8_MOBILE_BUILD.md) ·
[Журнал проверки установки](docs/SETUP_AUDIT.md).

## Новое в 1.3
* 🐾 **Котик-напарник** сидит в углу во время фокуса (моргает, машет хвостом). Нет мыши/клавиатуры 15 минут (в EXE — во всей Windows) → «Ты всё ещё в потоке или сделаем паузу? 🐾» · «Продолжаю 🐾» / «Взял паузу ☕» (перерыв 5 мин). В EXE — отдельное окно поверх всех программ. Навязчивый виджет «каждые 5 минут» убран.
* 🔒 **Синхронизация ПК ⇄ телефон** со сквозным шифрованием: облачная папка (Google Drive/OneDrive/iCloud/Dropbox) и/или бесплатный Supabase.
* 💬 **Цитаты**: 37 шт. с проверенными авторами, 6 категорий, грустные скрыты, смена раз в 5 минут и после отсутствия > 2,5 мин, «Больше не показывать эту», импорт JSON.
* 🌧 **Звуки**: дождь, кафе, библиотека, коричневый/розовый шум, океан, камин, ветер; громкость, старт с фокусом, плавное затухание в конце.
* 🌙 **Мягкий перенос** хвостов на сегодня/завтра одной кнопкой + достижение «Бережный план».
* ⌘ **Ctrl+K** — палитра команд с нечётким поиском.
* 🧱 Код разбит на ES-модули (`src/js/`), сборка esbuild, юнит- и E2E-тесты, CI гоняет тесты перед сборкой EXE. PWA-манифест и офлайн-режим.

Горячие клавиши: `Ctrl K` палитра · `/` поиск · `Q` захват · `N` задача · `Space` фокус · `F` режим фокуса · `C` сжатие · `L` бережный режим · `1–4` задачи · `5` привычки · `6` финансы · `7` мысли · глобально `Ctrl Alt Space` / `Ctrl Alt F`.
